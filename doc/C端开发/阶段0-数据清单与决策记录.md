# 阶段 0：数据清单与决策记录

版本：`stage0-data-v1`  
日期：2026-10-16  
状态：阶段 0 产物；实现和外部合规仍未完成。

## 本次范围确认

- 用户端：个人用户 C 端情感困境分析与沟通复盘。
- 页面/入口：当前阶段不开发网页；阶段 1 使用 CLI，阶段 3 才建设中文网页。
- 业务流程：自然语言/图片/语音输入 → 非文本转写确认 → 前置安全筛查 → 情境理解 → 有限澄清 → 分析与建议 → 输出检查 → 保存读回 → 总结/反馈/删除。
- 技术模块：Python 领域核心、Pydantic 契约、LangGraph 工作流、InputProvider、SpeechProvider、ModelProvider、SQLite Repository、脱敏事件日志；Web/FastAPI/PostgreSQL 属后续阶段。

## 阶段 0 冻结决策

1. 首轮只使用合成或明确获准、已脱敏材料；未完成数据流、服务商和危机升级审查前不接收真实敏感材料。
2. 改进授权独立于本次服务，默认 `denied`；拒绝不影响本次分析。
3. 图片/音频只能先生成待确认文本；未确认的 OCR/ASR 不得进入分析。
4. 高风险和操纵请求走安全/拒绝路径，不继续普通关系优化；不承诺实时人工危机服务。
5. 业务结果以 Repository 中保存并成功读回的版本为准；checkpoint 只服务流程恢复；Trace 不构成正确性证据。
6. 每轮最多一个决定性澄清问题，每次分析请求最多两次，可跳过；先交付经检查的有限分析再等待澄清。
7. 用户纠正创建新输入版本和新 run；旧结果、旧 TTS 不得覆盖或继续冒充当前版本。
8. 阶段 0 不锁定 LangGraph `1.2.15` 为已验证版本，只保留为候选基线；阶段 1 初始化时复核发布、Python、模型 Provider 和 checkpointer 兼容性并生成 lockfile。

## 数据清单与处理边界

| 数据类别 | 示例字段 | 阶段 1 存储/用途 | 是否进入日志/共享评测 |
|---|---|---|---|
| 输入元数据 | `session_id`、`input_version_id`、modality、provider、状态、时间 | SQLite；流程追踪 | 仅脱敏摘要；可进入合成评测结果 |
| 确认文本 | 用户手动文本或确认/修正后的 OCR/ASR 文本 | SQLite；分析输入 | 原文不进运行日志；合成案例可进入受控 `evals/cases` |
| 原始图片/音频 | 本地文件引用、哈希、大小、来源状态 | 阶段 1 仅真实 OCR 探针按最小范围临时处理 | 不进 Git、日志或共享评测；删除需可验证 |
| 情境结构 | 目标、事件、感受、用户解释、未知、风险信号 | SQLite；工作流状态/结果 | 只记录 ID/版本和脱敏状态 |
| 证据与结果 | Claim、EvidenceRef、Suggestion、风险回应、澄清问题 | SQLite；业务结果权威 | 评测记录 ID、版本和分数；不写敏感原文 |
| 授权 | purpose、notice_version、status、data_version_ids、时间 | SQLite；改进授权与撤回 | 记录授权状态和版本，不记录材料正文 |
| checkpoint | thread/run 状态、最小恢复字段 | 独立本地 checkpoint；仅恢复 | 不进入共享检索；删除必须覆盖 |
| 运行事件 | request/run/step、版本、耗时、状态、错误码 | JSONL；故障定位 | 禁止原始输入、完整 prompt、密钥 |
| 反馈/评测 | feedback type、rubric score、缺陷标签 | 阶段 1 可保存脱敏结果 | 无改进授权不得进入共享评测集 |

## 依赖与接口复核记录

- LangGraph：文档记录的 `1.2.15` 仅为候选基线，本阶段未重新核验上游发布或安装兼容性；阶段 1 需实际安装、锁定完整依赖并验证 checkpoint/interrupt-resume。
- Provider：阶段 0 只冻结 `InputProvider`、`SpeechProvider`、`ModelProvider` 接口方向；模型/OCR/ASR/TTS 服务商、数据传输地点、留存/训练/删除政策均待确认。
- 存储：阶段 1 使用 SQLite 业务 Repository 与独立本地 checkpoint；阶段 2 才评估 PostgreSQL 迁移；不把 checkpoint 当业务结果。
- 观测：Langfuse/OpenTelemetry 仍是候选，不作为阶段 1 必需依赖；若接入，默认只采集脱敏元数据。
