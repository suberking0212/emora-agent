# 项目文档索引

文档按产品方向和用途分开维护。当前个人用户方向拆分为“C端开发”和“C端产品设计”：前者负责首轮验证、工程方案和执行记录，后者负责完整的个人产品体验 PRD。学生/开发者是首批测试样本，不等于长期目标客群或企业客户。

口径分工：产品体验 PRD 定义功能、体验、隐私、安全与非目标；首轮验证 PRD 定义样本、假设与实验决策；工程设计定义实现；阶段计划的需求追踪表关联要求、设计、阶段与验收证据。冲突须显式记录范围决策并同步相关文档，不能靠工程选型或阶段延期隐式改变 PRD。历史探索记录不代表当前执行基线。

架构图位于[工程设计 §8.1「个人用户完整架构与必要接口」](C端开发/工程设计说明.md)，表示阶段 3 的目标架构；阶段 1/2 的建设边界在同节说明。当前均为文档设计，尚无业务代码实现。
