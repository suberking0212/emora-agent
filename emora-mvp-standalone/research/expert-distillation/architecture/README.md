# architecture/ · 图表

本目录包含三张 Mermaid 图（`.mmd` 源文件，GitHub/GitLab/多数 Markdown 渲染器可直接渲染，也可复制到 mermaid.live 出 PNG/SVG）。

- `01-professional-expertise-model.mmd`：九层专业能力模型（05 的图形化）。
- `02-expert-decision-mechanism.mmd`：专家决策机制（04 §11 条件化决策的表 → 决策树/流程）。
- `03-agent-capability-mapping.mmd`：能力 → Agent 架构元素映射（06 的图形化）。

## 渲染方式

1. 打开 https://mermaid.live
2. 将 `.mmd` 内容粘贴
3. 导出 PNG/SVG 后放回本目录（或直接由支持 mermaid 的文档工具内联渲染）
