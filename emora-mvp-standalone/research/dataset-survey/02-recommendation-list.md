## 三、需要专家审核的（用于 Emora 前的把关项）

> 判定标准：重构/半真实数据进入实际产品前，须由有专业背景者审核其专业正确性。

1. **CPsyCounD 全部对话**：因其是 LLM 从报告重构，部分对话可能存在"咨询师"回应过于模板化、过度积极、或不符合专业规范（如案例中已有"三赢原则""自爱≠自私"等说教式表述，需评估是否具备 Emora 期望的 MI 式"反映优先"）。→ **抽样专家审核后才能作为对模型/知识库的正样本。**
2. **PsyDial D1/D4 对话**：半真实重构，需抽检重构是否扭曲了原咨询师的真实意图；其 system prompt 的"咨询前中后期"策略可作为参考，但需与 Emora 的"非诊断、情感支持"边界对齐后再吸收。
3. **CPsyCounE / PsyDial-D101 的"golden 标准答案"**：作为评测时，gold 是否真的代表"好"的专业回应，需心理咨询背景者复核，避免把"说教式回应"误当 gold。
4. **性/心理疾病/危机类样本的敏感性**：CPsyCoun 九大主题含 Sex、Mental Disease，直接入库有风险，须**分类隔离 + 安全审核**，禁止进入 Emora 的普通情感支持输出流。

## 四、不会用于 Emora（明确排除）

- **ESConv 进入商用产品**：CC-BY-NC 4.0 + "academic use only"，Emora 商业用途下**不可用**；仅限研究者个人学习参考。
- **未获授权书的 CPsyCounR 进入产品**：授权书明确非商用+只读，违规即违约。
- **CPsyCoun 的 Sex / Mental Disease 类目直接入库**：与 Emora"非诊断、情感支持"定位冲突 + 敏感性风险。
- **任何"模型生成的模拟对话"当作"真实专家咨询记录"来宣称**：违反真实性红线。
